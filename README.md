# TIMELUX // Precision Engineered Digital Timepieces

A 3D scrollytelling portfolio website and high-ticket client acquisition engine for elite software engineering. Using the luxury mechanical watch as a metaphor for software architecture, Timelux targets the exact pain points of enterprise B2B buyers: reliability, speed, and the heavy business losses caused by "disconnected execution".

---

## ⚡ Quick Start

```bash
# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## 💎 Adding Your Own 3D Models & Visuals

The project includes an out-of-the-box procedural Three.js 3D mechanical watch with physical sapphire refraction, ticking second hand, oscillating balance wheel, and titanium case.

When you are ready to drop in your custom 3D files:
- Place your `.glb` or `.gltf` model in [`public/models/`](file:///Users/qaribiqbal/development/projects/Personal/timelux/public/models).
- Place video textures or macro footage in `public/videos/`.
